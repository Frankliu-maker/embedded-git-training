## 3、git的一些核心概念
工作区：平时写一些代码的地方
暂存区：点+号或者输入命令git add后，文件存放的地方
本地仓库：点对号或者输入git commit -m "提交信息"
远程仓库：点推送或者输入git push，之后代码就可以传送到github上面

## 4、gitflow的认识
main/master:稳定分支，正式版本
dev：日常开发使用
feature：开发人员本地建的分支，合并到dev后删除
release/hotfix：用于发布前测试和线上紧急救火
